# 🛒 Swiggy Instamart Sales Analysis Dashboard – Power BI Project


## 📌 Project Overview

This project presents an interactive **Sales Performance Dashboard** built in **Power BI** to analyze Swiggy Instamart’s business data. The dashboard provides detailed insights into Total Sales, Total Orders, Average Sales, and Average Rating, helping stakeholders understand performance trends and customer behavior.

The report is designed with dynamic filters and KPI cards to enable data-driven decision-making and business intelligence analysis.

---

## 🎯 Key Objectives

* Analyze overall sales and order performance
* Compare sales across **City Types (Tier 1, Tier 2, Tier 3)**
* Evaluate performance by **Shop Size and Shop Type**
* Identify **Top 10 Categories** contributing to revenue
* Track order trends based on **Shop Opening Year**
* Measure customer satisfaction using **Average Ratings**

## 📊 Dashboard Features

✔ KPI Cards (Total Sales, Avg Sales, Total Orders, Avg Rating)
✔ Sales Analysis by City Type
✔ Orders Distribution by City Tier
✔ Sales by Shop Size (Small, Medium, High)
✔ Category-wise Top 10 Sales Contribution
✔ Shop Type Performance Table
✔ Year-wise Order Trend Analysis
✔ Interactive Slicers & Filters

---

## 📈 Key Insights

* Tier 3 cities generated the highest total sales contribution.
* Supermarket Type 1 contributed the maximum revenue and order volume.
* Fruits & Vegetables and Snack Foods are top-performing categories.
* Sales distribution varies significantly across shop sizes.
* Customer ratings remain consistently above 3.9, indicating positive satisfaction levels.
